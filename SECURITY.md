# Security policy

## Supported versions

Fixes go into the latest release on npm (`@sveltier/ui`), so upgrade to it before reporting.

## Reporting a vulnerability

Please do not open a public issue. Report it privately through GitHub: on the
[Security tab](https://github.com/sveltier/sveltier/security) of this repository, choose
**Report a vulnerability**. Include the version, what an attacker could do, and the steps or code
that show it.

The maintainers will reply as soon as they can. Once a fix is released, the advisory is published with
credit to you, unless you would rather not be named.
