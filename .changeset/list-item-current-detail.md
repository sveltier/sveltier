An active ListItem that is a button is marked `aria-current="true"`, as an active link is marked `aria-current="page"`, for the row that is open, such as the current lesson. A new `detail` snippet puts content at the end of the row inside its link or button, such as a count or a progress, so it is part of the row's name; `append` stays outside, for controls.
