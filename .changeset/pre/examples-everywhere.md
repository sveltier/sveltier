Every public props type and function now has an `@example` in its TSDoc, so editors and coding agents see how to use it straight from the declarations: Alert, Avatar, Badge, Button, ButtonGroup, Card, Chip, Divider, Icon, List, ListItem, ProgressLinear, ProgressCircular, SegmentedControl, Skeleton, Tabs, the shared props, `useTheme`, `useDisplay`, `useLocale`, `themeCss`, `themeScript`, the colour helpers and the focus, keyboard and motion primitives.
